Results Page
============

SAM displays tables and graphs of results from the performance and financial models on the Results page tabs.

For detailed descriptions of key output metrics shown in the Results page tables and graphs, see :doc:`../financial-metrics/index` and :doc:`../performance-metrics/index`.

For a general description of the Results page with screenshots, see :doc:`Results <../getting-started/results_page>`.
