Macros
~~~~~~

A macro is a pre-written :doc:`LK script <../reference/lk_script>` that comes with SAM. Macros are designed to allow you to run a script without having to write it.

**To run a macro:**

1. Click **Macros**.

   .. image:: ../images/SS_MainWindow-MacrosButton.png
      :align: center
      :alt: SS_MainWindow-MacrosButton.png

2. Choose a macro from the list, and review the macro description and instructions.

3. If the macro has parameters listed on the right side of the page, review and modify them as necessary.

4. Click **Run macro** at the top of the page to run the macro. The console at the bottom of the page may display progress and information as the macro runs.
